# First run archive (frozen snapshot)

This folder is a **copy of the project materials used for the first full experiment wave** (150 agents, five literature-prime conditions), taken **before** you edit instructions at the repo root for a second run.

**Included:** data, `conditions.tsv`, all `PRIME_*.md` files, `INSTRUCTIONS_SHARED.md`, `DID_METHODOLOGY.md`, `DATA_DICTIONARY.md`, `scripts/`, `package.json`, `package-lock.json`, `RUN_INSTRUCTIONS.md`, `README.md`, and `.gitignore`.

**Excluded from the copy (by design):** `node_modules/`, `output/` (aggregated results live outside this snapshot), `.git/`.

**Not a runnable duplicate out of the box:** run agents from the **repository root** after `npm install`; this tree is for **reference and diffing** against your second-wave edits.

For a narrative of design changes and troubleshooting, see **`PROJECT_LOG.md`** at the repository root (that file is not duplicated here unless you copy it in).
